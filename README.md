# Landing Page — Dayane Amaral

Landing page institucional premium (HTML5 + CSS3 puro) para **Dayane Amaral | Consultoria Estratégica Financeira Associativa**, criadora do **Método 4E – Gestão Estratégica Associativa**.

## Estrutura
- `/index.html`
- `/style.css`
- `/script.js`
- `/assets/images/*`

## Deploy na Vercel
1. Importe este repositório na Vercel
2. Framework preset: **Other** (site estático)
3. Build command: vazio
4. Output directory: `/`

## Observações
- Formulário com validação básica em JS.
- Envio real do formulário não está conectado (pode integrar com Vercel Functions ou WhatsApp).
